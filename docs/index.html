Why it exists

Agents are hard-wired to one API. The models you want speak another.

Coding-agent CLIs speak Anthropic's /v1/messages; most of the model world speaks OpenAI's /v1/chat/completions. Three problems follow.

Lock-in

Without a translator you can't use the agent with those models at all. One wire protocol locks you to one slice of the ecosystem.

Cost & access

Running an agent loop against a frontier API adds up. Free tiers and local models let students, hobbyists, and cost-sensitive teams keep working.

Reliability

Free tiers rate-limit hard, so no single provider is dependable. An ordered fallback chain tries the next target when one is throttled.

How it works

A request hops across the gap, correctly.

The same journey every message takes — in and out, including the streaming event sequence.

Agent

Sends

Anthropic Messages API over HTTP + SSE.

Ingress

Accepts

/v1/messages, validated locally.

Route + translate

Maps

Model/tier → targets; Anthropic ↔ provider.

Provider

Answers

Free, local, or paid — your account, your key.

The response takes the journey back the other way. The hard part is reconstructing the Anthropic SSE sequence (message_start → content_block_delta → message_stop) from provider chunks — including partial tool-call arguments. That streaming translation is the product; see the architecture.

Security-first, by default

It holds your keys and forwards your prompts. The defaults assume that.

SSRF guard

Every outbound call validates each resolved IP at dial time — defeating DNS rebinding — and blocks loopback, RFC1918, link-local, and cloud metadata (IPv4, IPv6, and IPv4-mapped). Redirects are disabled.

Secrets, handled

OS keychain, then an AES-256-GCM encrypted file, then 0600 plaintext with a warning. The config stores a reference, not the value. Auth headers and secret patterns are scrubbed from every log.

Loopback by default

The server binds 127.0.0.1. A non-loopback bind is explicit, warned, and requires an ingress token — so the proxy is never exposed to a network unauthenticated.

Mapped to OWASP Top 10 for LLM Applications (2026) and API Security Top 10. It's a local, single-user tool — not a multi-tenant security boundary. Full detail in the architecture & threat model.

What "free" honestly means

A realistic aggregate across providers is on the order of tens to hundreds of millions of free tokens per month, bound by per-minute and per-day throttles and per-provider (often per-organization) limits. Availability is the providers' and changes without notice. That is not "unlimited" and not "1B+".
