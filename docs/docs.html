01 — Quick start

Up and running in a minute.

Install the binary

Builds a single static binary with the Go toolchain — nothing else to run.

$ go install github.com/dibakshya01/freebie-frog/cmd/freebie@latest

Prefer building from a clone? make build drops the binary at ./bin/freebie.

Check your environment

doctor validates your config and confirms the port is bindable before you start.

freebie doctor
$ freebie doctor
freebie-frog doctor
  version:    dev
  go runtime: go1.24 (linux/amd64)
  [ok]   config loaded and valid
  [ok]   address 127.0.0.1:4000 is bindable
all checks passed

Start the server

Binds 127.0.0.1:4000 by default and streams Server-Sent Events. Ctrl-C to stop.

$ freebie serve --config ./config.json

02 — Configuration

One JSON file: providers, keys, and routing.

Resolved as defaults → JSON file → environment variables, then validated. The config stores a reference to each key, never the key itself.

config.json 
{
  "server": {
    "addr": "127.0.0.1:4000",
    "read_timeout": "30s",
    "write_timeout": "0s",
    "shutdown_timeout": "15s"
  },
  "log": { "level": "info", "format": "text" },
  "providers": {
    "groq": {
      "type": "openai",
      "base_url": "https://api.groq.com/openai/v1",
      "api_key_ref": "env:GROQ_API_KEY",
      "models": ["llama-3.3-70b-versatile", "llama-3.1-8b-instant"]
    },
    "openrouter": {
      "type": "openai",
      "base_url": "https://openrouter.ai/api/v1",
      "api_key_ref": "env:OPENROUTER_API_KEY",
      "models": ["deepseek/deepseek-chat-v3:free"]
    },
    "ollama": {
      "type": "openai",
      "base_url": "http://localhost:11434/v1",
      "allow_local": true,
      "models": ["qwen2.5-coder:7b"]
    }
  },
  "models": {
    "default": [
      "groq/llama-3.3-70b-versatile",
      "openrouter/deepseek/deepseek-chat-v3:free",
      "ollama/qwen2.5-coder:7b"
    ],
    "tiers": {
      "haiku": ["groq/llama-3.1-8b-instant", "ollama/qwen2.5-coder:7b"]
    }
  }
}
api_key_ref
A reference, not the secret: env:NAME, an OS-keychain entry, or an encrypted-file entry. The value is resolved at runtime and never written to the config or the logs.
type
openai covers the whole OpenAI-compatible field. A native gemini adapter and an anthropic passthrough are the other two.
allow_local
A scoped opt-in that allowlists one local host for a provider (e.g. Ollama). Dial-time IP checks still apply — it's not a blanket disable of the SSRF guard.
models.default
The ordered fallback chain. Requests try each provider/model in turn on a retryable failure.
models.tiers
Map an incoming family (opus/sonnet/haiku/fable, matched by substring) to its own ordered chain.

Never commit secrets. Keep keys in environment variables or a secret backend. write_timeout is 0 on purpose — the proxy's job is long-lived SSE streaming, which a non-zero write timeout would cut off.

Override any server field from the environment: FREEBIE_SERVER_ADDR, FREEBIE_LOG_LEVEL, FREEBIE_LOG_FORMAT, FREEBIE_SERVER_READ_TIMEOUT, FREEBIE_SERVER_WRITE_TIMEOUT, FREEBIE_SERVER_SHUTDOWN_TIMEOUT.

03 — Use with Claude Code

Point the agent at the proxy.

Claude Code honors ANTHROPIC_BASE_URL and an auth token — that's the whole hook. Set them, start the server, run the agent.

terminal 
# 1. start freebie-frog (binds 127.0.0.1:4000)
$ freebie serve --config ./config.json

# 2. in another shell, point the agent at it
$ export ANTHROPIC_BASE_URL="http://localhost:4000"
$ export ANTHROPIC_AUTH_TOKEN="local-dev"

# 3. run your agent as usual
$ claude

On loopback the token is only a formality; set it to any value. If you bind to a non-loopback address, a real ingress token becomes mandatory.

What the agent sees

An ordinary Anthropic endpoint: /v1/messages, /v1/messages/count_tokens, and /v1/models. Streaming returns the usual SSE events, so the agent's tool loop keeps working.

What happens behind it

The incoming model is matched to its routing chain, the request is translated, and the first reachable provider answers. If one is throttled before streaming begins, the next is tried automatically.

The same ANTHROPIC_BASE_URL hook works for any Anthropic-API agent (Codex, Aider, and others). freebie run <agent> will launch a supported agent with these variables set for you.

04 — CLI reference

Six commands.

All commands below ship in the current build.

CommandWhat it doesStatus
serveStart the proxy server. Flag: --config <path> (defaults to ./config.json if present).shipped
runLaunch a supported agent CLI (freebie run claude) with ANTHROPIC_BASE_URL and the auth token pre-set.shipped
configPrint the resolved configuration (defaults + file + env) and exit.shipped
doctorRun diagnostics: validate config and confirm the server address is bindable.shipped
providersList configured providers and the models each exposes.shipped
versionPrint the build version.shipped

The full suite is implemented and tested: the translating core (streaming + non-streaming), the router with multi-provider fallback, OpenAI-compatible / Gemini / Anthropic-passthrough adapters, security hardening (SSRF guard, secret backends, ingress auth), the agent launchers, and the read-only admin dashboard. It is pre-1.0 — evaluate it before depending on it for anything critical.
